⏱️ 9. Timing Explained

Extension me jo time dikhta hai (e.g., "110ms") wo sirf extension ka apna processing time hai.

Extension ka Timer:

→ Poll detect hua (startTime)
→ 50ms wait (pollDelay)
→ Option click kiya
→ 25ms wait (submitDelay)
→ Submit click kiya (endTime)

Total = endTime - startTime = ~110ms

PW ka Timer (jo PW dikhata hai):

→ Teacher poll bhejta hai
→ ~300ms: Internet (server → tumhara device)
→ ~200ms: React rendering (poll screen pe aata hai)
→ ~110ms: Extension ka kaam
→ ~200ms: Internet (submit → PW server)

PW Total = ~810ms

💡 Summary: Extension ~110ms me kaam karta hai. PW ka total ~800ms hai. Difference (~700ms) internet + PW rendering ka hai — extension ke control me nahi.

❓ 10. FAQ

Q: Green Orb nahi dikh raha?
A: Check karo: 1) Lecture page pe ho? 2) Extension enabled hai? 3) Page refresh karo. Orb 50-500ms me detect ho jata hai.
Q: Orb tap karne pe expand nahi hota?
A: Ek baar zor se tap karo (drag mat karo). Agar phir bhi na ho toh page refresh karo.
Q: Poll miss ho gaya — kya kare?
A: Error Log check karo dashboard me. Reason dikhai dega. Usually: answer select nahi tha ya submit button nahi mila.
Q: Extension poll answer karta hai but PW me mark nahi hota?
A: Answer Delay badhao (100ms ya 260ms try karo). Slow internet pe 50ms kabhi-kabhi enough nahi hota.
Q: 📊 Dashboard button kaam nahi karta?
A: Kiwi Menu → Extensions → PW Poll Sniper icon tap karo — dashboard khulega. Ya browser restart karo.
Q: Har poll ke baad answer reset kyu hota hai?
A: Ye by design hai — har poll ka answer alag ho sakta hai. Poll ke baad dobara select karo.
Q: Battery bahut khaata hai?
A: Detection Speed 200ms ya 500ms set karo. Jab lecture nahi dekh rahe, extension OFF kar do.
Q: Kya ye safe hai? PW pakdega toh?
A: Extension normal user ki tarah click karta hai (React events use karta hai). Koi network interception nahi karta. But use at your own risk.
