🎯 What Is This?

PW Poll Sniper Mobile ek Chrome extension hai jo Physics Wallah (pw.live) website pe automatically polls detect karta hai aur aapka pre-selected answer tick karke submit kar deta hai.


Works on: LIVE lectures + RECORDED lectures

Browser: Kiwi Browser (Android) — because normal Chrome mobile doesn't support extensions

Response Time: 800-2000ms (with human-like delay)

📲 Installation (Step by Step)

1

Step 1: Install Kiwi Browser

Google Play Store se Kiwi Browser download karo. Normal Chrome mobile pe extensions kaam nahi karte, isliye Kiwi zaroori hai.

2

Step 2: Download Extension

Upar diye gaye green "Download Extension" button pe click karo. pw-poll-sniper-mobile.zip file download hogi.

3

Step 3: Extract ZIP File

Downloaded pw-poll-sniper-mobile.zip file ko kisi folder mein extract karo. Phone ka file manager ya ZArchiver app use karo.


⚠️ Important: Extract karo, zip mat use karo directly!

4

Step 4: Open Kiwi Browser → Extensions

Kiwi Browser kholo → ⋮ (3 dots menu) → Extensions pe tap karo.

5

Step 5: Enable Developer Mode

Extensions page pe "Developer mode" toggle ON karo (top-right corner pe).

6

Step 6: Load Extension

"+ (from .zip/.crx/.user.js)" button pe tap karo → Extracted folder select karo (pw-poll-sniper-mobile).

7

Step 7: Verify Installation ✅

Extensions list mein "PW Poll Sniper Mobile" dikhna chahiye. Extension icon (⚡) browser toolbar mein aa jayega.

🎮 How to Use (Step by Step)

1

Open PW Lecture

Kiwi Browser mein pw.live kholo → Login karo → Koi bhi LIVE ya RECORDED lecture kholo.

2

Enable Extension

Extension icon (⚡) tap karo → Toggle ON karo. Green circle screen pe bottom-right mein dikhega.

3

Tap Green Circle

Green circle pe tap karo → 5 buttons dikhenge: A, B, C, D, _

4

Select Answer

A/B/C/D mein se koi ek tap karo. Panel automatically close ho jayega (300ms). Circle pe selected answer blue mein dikhega.

5

Wait for Poll

Jab poll aayega, extension automatically: poll icon detect karega → panel open karega → answer select karega → submit karega!

6

Poll Answered! ✅

Poll successfully answer ho jayega. Circle reset hoke _ dikha dega. Next poll ke liye phir se answer select karo.

🟢 Green Circle States

_ (Underscore) — No answer selected. Poll aayega toh open hoga but answer nahi karega.
A / B / C / D — Answer selected hai. Jab poll aayega, ye answer automatically tick hoga.
Small Green Dot — Extension active hai (top-right corner pe chhota sa green dot).

📺 LIVE vs RECORDED Lectures

LIVE Lectures

Poll Icon: #poll-icon

Inactive Color: #ffffff (white)

Active Color: Blue/colored (any non-white)

Detection: Icon color change detect hota hai


Jab teacher poll bhejta hai, icon white se blue ho jata hai. Extension detect karta hai aur automatically poll panel open karta hai.

RECORDED Lectures

Poll Icon: #record-poll-icon

Inactive Color: #ffffff (white)

Active Color: var(--primary) (CSS variable → blue)

Detection: Icon color + computed style fallback


Recorded lectures mein poll icon alag ID use karta hai. Extension dono check karta hai aur CSS variables ko bhi detect kar sakta hai.

🔧 Troubleshooting

❌ Extension load nahi ho raha

Fix: ZIP file ko extract karo, folder load karo. Direct ZIP load mat karo. Developer mode ON hona chahiye.

❌ Green circle nahi dikh raha

Fix: Extension toggle ON karo (popup menu se). Lecture page pe hona chahiye (video player wala page).

❌ Poll detect nahi ho raha

Fix: Auto Open Poll setting ON hona chahiye. Answer select hona chahiye (circle pe A/B/C/D dikhe, _ nahi).

❌ Answer select nahi ho raha

Fix: Green circle tap karo → A/B/C/D button tap karo → Circle pe answer blue mein dikhega. Agar _ hai toh answer select nahi hua.

❌ Panel khul nahi raha

Fix: Page refresh karo. Extension disable-enable karo. Kiwi Browser restart karo.

❌ Poll submit nahi ho raha

Fix: Auto Submit setting ON hona chahiye. Poll active hona chahiye (already answered nahi hona chahiye).

❓ FAQ

Kya ye safe hai?

Haan, human-like delay ON rakhne pe safe hai. 500-1500ms delay natural lagta hai. Bahut fast answer suspicious hota hai.

Kya Chrome mobile pe kaam karega?

Nahi, normal Chrome mobile pe extensions kaam nahi karte. Kiwi Browser use karo — ye Chrome extensions support karta hai.

Kya iPhone pe kaam karega?

Nahi, Safari iOS pe Chrome extensions kaam nahi karte. Sirf Android pe Kiwi Browser mein kaam karta hai.

Poll count kahan dikhega?

Popup menu ke Stats section mein. Green circle pe badge nahi hai — clean design ke liye. Dashboard mein bhi dekh sakte ho.

Kya exam mein use kar sakte hain?

⚠️ Nahi! Exams mein proctoring ho sakti hai. Sirf practice polls ke liye use karo. Graded assessments mein risk hai.

Extension uninstall kaise karein?

Kiwi Browser → ⋮ → Extensions → PW Poll Sniper Mobile → Remove → Confirm.
